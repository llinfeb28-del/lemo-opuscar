# 久坐族自测：5 个信号你中了几个？

风格：50s 扁平卡通（`styles/midcentury-toon`）· 竖屏 1080×1920 · 24 fps · 约 48.5 s
无配乐、无配音（用户自己加音乐）。交付两版：**卡点音效版**（拟音 + 房间底噪，无音乐）和**纯净版**（无声）。
节拍网格：**120 BPM**（每拍 0.5 s，每小节 2 s），所有转场、盖章、动作都落在拍点上，方便用户套 120 BPM 的音乐。

**配色**（本片自定，不同于示范片）：燕麦色纸底、暖黑墨线；番茄红只给主角的 polo 衫，从头到尾不变；
各段底色轮换：开场灰蓝 → 标题燕麦 → 信号 沙色 / 芥末黄 / 橄榄绿 / 灰蓝 / 梅紫 → 判定燕麦 → 起身青绿 → 动作 橄榄 / 芥末 / 灰蓝 → 总结燕麦。

## 1. 三个候选结构

**A. 自测清单卡（选用）**
顶部一条 5 格徽章栏，每过一个信号就盖上一个章、留一个短标签；中间是大号人物把这个信号"演"出来；
5 个信号之后，观众心里已经数完了"中了几个"。转折：人物从椅子上站起来，整页颜色跟着他翻过去；然后是 3 个动作；
最后一张静止 4 秒的"截图帧"。

**B. 一天时间线**
从早 9 点到晚 6 点，时钟每走几个小时，身上就冒出一个症状（11 点脖子、3 点腰、5 点脚踝），最后起身。
放弃理由：时间线需要更长的铺垫，信号之间不够分明，观众不好数"中了几个"，而数数正是评论钩子。

**C. 左右/上下对照**
每格上半是错误坐姿（信号），下半是对应动作。
放弃理由：5 个信号和 3 个动作不能一一对应；竖屏一分为二，人物只有半屏高；每屏字数翻倍，读不完。

**选 A 的理由**：抖音的互动点是"数数"，清单让数数变得自然；顶部徽章栏一直在画面上，观众随时能对照；
"站起来"是整片唯一的大动作，正好做转折和招牌镜头。

开场画面、结尾和声音形状都由题目决定：开场是"时钟飞转、人越坐越塌"，结尾是"人站着、时钟正常走"，
首尾呼应"坐了一整天？"→"坐久了，就起来做一遍"。

## 2. 一句话梗概和弧线

一个上班族坐塌了一整天，5 个信号把他"点名"，他终于站起来，学会 3 个 30 秒就能做完的动作。

- **铺垫**：时钟从 9 点飞到 18 点，人一格一格坐塌下去。
- **转折**：清单盖完，全场静音半拍，人站起来，整页颜色从疲惫的芥末黄翻成清爽的青绿。
- **结尾**：3 个动作总结成一张静止卡，人站在桌边，邀请观众"评论区打数字"。

## 5. 节拍表（秒）

- 0.0 第一帧就有人、桌、时钟；0.1–0.6 写出"坐了一整天？"
- 0.5、1.0、1.5、2.0、2.5 每拍人塌一格；时钟越转越快，滴答声越来越密
- 3.0 时钟"叮"的一声，标题盖章
- 4.0 / 4.5 / 5.0 / 5.5 / 6.0 五个空徽章依次盖上
- 6.5–7.0 ① 号徽章放大，圆形转场
- 7.0 ① 盖章、标签"8小时"落进徽章栏；7.5–9.5 时间条一拍一格填满 8 格
- 10.5 ② 盖章；11.5 蜘蛛垂下，12.5 停在头顶；13.0 人眨一下眼
- 14.0 ③ 盖章；14.4 手抬到后颈（预备→动作→回弹）；14.75 放大镜头；15.0 酸痛线弹出
- 17.0 ④ 盖章；17.5 手滑向后腰，镜头下摇；18.5 皱眉
- 20.0 ⑤ 盖章；20.5 放大脚踝；21.0–22.5 每拍鼓一下，共 4 下
- 23.5 徽章栏降到中央；24.0 "只要中了 1 个"
- 26.0 全场静音（底噪也关）
- 26.5 椅子刮地声 + 站起；色块从下往上翻；26.75 "就该起来动一动！"
- 30.0 / 34.5 / 39.0 三个步骤开始；每步 +0.25 标题，+0.75 说明，+1.25 次数标签；动作重复 2 次，落在拍点
- 43.5 总结卡翻上来；43.8 口号；44.25 评论引导；44.5 / 45.0 / 45.5 三个勾；之后静止到 48.5；48.0 "叮"

## 6. 节拍网格

- 120 BPM，4/4，每小节 2.0 s，全片 97 拍。
- 转场都在偶数拍（整小节）上：3.0、7.0、14.0、17.0、20.0、30.0、43.5（半小节，作为呼吸）。
- 加速：开场时钟滴答从每拍 1 下加到每拍 4 下；放慢：转折前的静音半拍；呼吸：总结卡静止 4 秒。
- 本片不出音乐；音效的节奏就是给用户音乐的对位参考。

## 7. 声音设计表

| 段落 | 底噪 | 主要拟音 | 音乐 |
|---|---|---|---|
| 开场 | 温暖房间底噪（低通棕噪，很轻） | 打字咔嗒、时钟滴答加速、18 点"叮" | 无（用户自配） |
| 标题 | 同上 | 盖章（闷橡胶章）×6 | 无 |
| 信号 ①–⑤ | 同上 | 盖章；时间条"嘀"；蜘蛛下垂"啾—"；僵硬线"嘣"；手摩擦布料；脚踝鼓起"噗" | 无 |
| 判定 | 底噪 → 26.0 全部静音 | 徽章栏落下"刷"；文字弹出 | 无 |
| 起身 | 26.5 重新进入 | 椅子刮地 + 弹出"啵"（静音后第一声）；色块翻页"唰" | 无 |
| 动作 ×3 | 底噪 | 步骤标题纸声、圆形转场"嚓"、箭头滑哨、动作落点轻敲、次数标签"叮" | 无 |
| 总结 | 只剩底噪 + 轻滴答 | 卡片落定、最后"叮" | 无 |

声音转场：起身的椅子刮地声比画面早 2 帧进入（J-cut）；18:00 的"叮"越过开场到标题卡的硬切继续响（L-cut）。
纯净版去掉所有声音，只保留静音音轨。

## 8. 字幕和标题设计

- 本片无旁白，画面上的字就是内容，不另出 `.srt`。
- 大标题"久坐族自测"：站酷庆科黄油体（复古展示体），墨色字 + 错位番茄红底版。
- 每屏大字（信号、判定、步骤名、总结）：思源宋体 Black（Noto Serif SC 900），对应风格里的粗衬线（slab）角色，墨色字 + 错位纸色底版。
  第一版用的是庆科黄油体，缩到手机大小时"够、僵、踝、个"等复杂字发糊，所以换成更清楚的粗宋。
- 说明、标签：思源黑体（Noto Sans SC）500/700，对应风格里 Jost 的角色。
- 开场问句（引子）：站酷快乐体，写出来，并从开场一直留到标题卡。
- 小装饰：拉丁字母"STEP 1 OF 3"用 Jost 600 加字距；数字徽章和"8h"用 Alfa Slab One。
- 安全区：重要文字放在 x 60–940、y 170–1520 之内，避开抖音右侧按钮栏和底部文案区。
- 读字时间：中文按 4.5 字/秒 + 1.5 秒计算，`readcheck.mjs` 逐帧检查。
